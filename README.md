# Homebrew Tap for Crenox

Official Homebrew tap for [Crenox](https://github.com/crenoxhq/crenox) — zero-dependency Git pre-commit secret scanner and credentials detector written in pure Go.

## Installation

```bash
brew tap crenoxhq/crenox
brew install crenox
```

## Documentation

Full documentation, benchmarks, and release binaries are available at [crenoxhq.github.io/crenox](https://crenoxhq.github.io/crenox/).
